# Basalt

**Basalt** is a purely personal, opinionated project. It is not a product. It is not a startup. It is one person's tool, built for one person's workflow.

Do not expect community friendliness. There is no roadmap committee, no feature voting, and no support team. If the project works for you, great. If it doesn't, that is expected. I am not even interested in providing prebuilt binaries on the releases page, if you do find them, that's a gift. Don't consider it a bare minimum.

## Name

The name "Basalt" is a respectful nod to [Obsidian](https://obsidian.md). Basalt is **not** a competitor. It is a different tool, built for different reasons. The nod is gratitude for inspiration, not a declaration of war.

## License

MIT. Not because I'm a saint — because I don't see any profit in keeping this proprietary. Use it, fork it, sell it, whatever. The license tells you what you can do.

## Features

There are a lot of features planned. **Do not ask me what features I should create.** I am not taking feature requests.

If you want a feature: **fork the repository and code it yourself.** That is the entire contribution model.

## Status

Personal project. Expect rough edges. Expect breaking changes. Expect that the author's priorities are not your priorities.
